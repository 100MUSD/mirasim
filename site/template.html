01

Mirasim 是什么

One Agent IDE —— 把「写代码的 agent」和「替你测试的模拟用户」装进同一个工作台。

传统流程里，你用一个工具写代码、再手动点开页面验证。Mirasim 的思路是把这两端接起来：编程 agent 在工作台里并行开工，构建完成后由模拟用户在真实浏览器、真实移动模拟器里实际使用你的产品，把第一手反馈带回来。以下是官方主页列出的核心能力：

WORKBENCH

多项目工作台

多个项目并列打开，每个项目拥有独立的会话、agent 与模型配置，互不干扰。

SESSIONS

多会话并行 + 内置编辑器

同时运行多个 agent 会话，配合类 VS Code 编辑器随手改代码，移动端也能继续工作。

TUI ⇄ GUI

终端与图形界面一键切换

同一套工作流，既可以在 TUI 里键盘流操作，也可以切到 GUI 里点选浏览。

BROWSER

浏览器自动化：读结构而非截图

Agent 以文本结构读取页面（官方数据：约 184 B 对比截图 60 KB，传输量差约 330 倍），驱动真实 Chrome 与真实用户配置文件。

MOBILE / MAC

Mac 应用与移动模拟器

用同样的方式驱动 Mac 应用、iOS 模拟器和 Android 模拟器——移动端产品也能被模拟用户测试。

ONE TOOL

单一工具入口，省上下文

官方称每轮工具开销约 1k tokens（对比挂 30 个工具 schema 约 53k tokens），把上下文留给真正的工作。

产品目前处于 Alpha 阶段，官方提示 "Expect rough edges"（会有毛边）。安装后应用会自动保持更新。

常见问题

最常被问到的几件事。

Mirasim 是免费的吗？

是——持邀请码使用免费，产品跑在你自己的模型账号（Claude Code、Codex 等订阅或 API key）上，Mirasim 不额外收费。只有 computer use 和模拟用户这两类功能需要付费额度或自备 key。

没有邀请码能用吗？

不能，目前是邀请制。直接用本站站长的邀请码 {{INVITE_CODE}} 即可激活；注册后你会得到自己的码，也可以去官方 Discord 索取。

支持哪些平台？

macOS 桌面版（Apple Silicon，macOS 13+）、macOS 命令行版、Android APK（侧载）、VS Code 扩展。iOS 在 TestFlight 内测中，公开邀请尚未开放。暂无 Intel Mac 与 Windows 版本。

「邀请 3 人送一个月 Basic」怎么核算？

被邀请者必须真实使用 Mirasim——官方明确「仅注册不算数」，需要登录、开会话、实际工作，官方会核查后按 3 / 5 / 10 人分别兑换 1 个月 Basic / Pro / Max。

如何确认安装包没被篡改？

本站下载表已列出每个文件的 SHA-256（点击可复制），也可下载官方 SHA256SUMS 文件后运行 shasum -a 256 -c SHA256SUMS --ignore-missing 校验。所有下载链接均直连官方 CDN（cdn-assets.mirasim.ai），本站不托管任何安装包。
